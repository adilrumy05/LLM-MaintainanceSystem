feat(rag): inline manual figures under [[p:NNN]] page citations

Three handoffs between Qdrant and the screen were silently dropping
manual figures, and a fourth gap meant the client never placed a figure
next to the instruction that referenced it. All four are fixed.

1. Python _enrich_sources_with_images rebuilt every URL from paths
   instead of using the url field ingest already wrote, and the rebuild
   double-prefixed "output/". Now: url is used when present, path-build
   is a fallback, output/ prefix is handled with or without leading
   slash, dedup is by url not src_path, caption is carried through.

2. server.js mirrors image-chunk URLs from context_blocks onto the
   matching source by (document_group_id, filename, page). Safety net
   until the Python fix is confirmed against a live query.

3. server.js prompt now instructs the model to emit [[p:NNN]] instead
   of bare parentheticals. Bare (122) is indistinguishable from the
   torque values, ohm readings, and quantities in the same manuals.

4. BotMessage.renderCitationsWithImages converts [[p:NNN]] to "(122)"
   and appends the page figure as markdown right after the citation.
   markdownConfig gains an image rule -- RN's default renders a
   zero-height element and nothing appears.

Sources list itself is unchanged. Only its expandable thumbnail and the
answer body change.
